# Design doc

For work that takes more than a week. Put it in `docs/design/<slug>.md` with sections Goals,
Non-goals, Proposed approach, Rollout plan, Risks and Open questions. Circulate it for review
before the build starts. A single technical decision with its reasons is an ADR instead.
