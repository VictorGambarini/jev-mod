# Release notes

Write to `docs/releases/<version>.md` for readers who are not engineers. Lead with the benefit,
group by theme, and leave out internal refactors. Link each item to its help-centre article.
This is a rewrite of the changelog for customers; it does not replace the changelog entry itself.
