# Runbook

Put it in `docs/runbooks/<alert-name>.md`. Sections: When this fires, First checks, Fix, Escalate,
Verify. Commands go in code blocks, one action per numbered step. Written ahead of time, not after
an incident; an incident write-up is a different document.
